# System Development – React, TypeScript & MongoDB Full-Stack Lessons  
*In Progress at SENAI*

**Course:** Technical Course in Systems Development  
**Subject:** System Development  
**Instructor:** Nicolas Marques  

This repository contains lessons, exercises, and full-stack applications developed throughout the System Development subject, focusing on modern web technologies such as React with TypeScript, Node.js, Express, MongoDB with Mongoose, and API communication using Axios.

The projects emphasize the development of scalable and maintainable applications, combining front-end and back-end technologies to simulate real-world software development practices.

## The materials are designed to:

- Strengthen full-stack development skills using modern technologies.
- Build responsive and component-based user interfaces with React and TypeScript.
- Develop RESTful APIs using Node.js and Express.
- Work with MongoDB databases using Mongoose for schema modeling and data management.
- Perform API requests and data integration using Axios.
- Apply best practices for code organization, modularization, and maintainability.
- Understand client-server communication in real applications.

---

# Running the Front-End (React + TypeScript)

To run the front-end applications, make sure you have Node.js and npm (or yarn) installed.

## Install dependencies and start the development server:

```bash
npm install
npm run dev
```

---

# Running the Back-End (Express + MongoDB)

To run the back-end projects, you need Node.js and a MongoDB instance (local or cloud).

## Install dependencies and start the server:

```bash
npm install
npm run server
```

Make sure to configure your MongoDB connection string and environment variables in a `.env` file.
