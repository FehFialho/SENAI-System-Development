# Controller

## Por que utilizar?

1. Mistura lógica de negócio com rotas deixando o código desorganizado
2. Aumenta a complexidade, dificil de entender e ajustar
3. Dificulta a Reutilização, causa duplicação
4. Complica Testes das regras de negócio
