# Middleware

## Introdução
- Funções intermediárias no ciclo de requisição e resposta
- Fica entre o cliente e o servidor
- Utilizados para:
    1. Autenticação
    2. Tratamento de Erros
    3. Manipulação de Logs
    4. Parsing de Dados
    5. Outros...

## Ciclo de Requisição no Express

1. Cliente envia requisição → método, URL, headers e corpo.

2. Express recebe ```req``` e ```res``` → objetos que representam requisição e resposta.

3. Middlewares processam a requisição → podem validar, autenticar ou modificar dados e chamam ```next()```.

4. Rota ou controller final → processa dados e envia resposta com ```res```.

5. Resposta chega ao cliente → ciclo concluído.
